# 貨櫃港口 PORT

依〈FIRELINE 地圖生成規格〉設計。座標：x 由西（A 隊）到東（B 隊）-41～41，z 由北到南 -29～29，單位公尺。
地圖左右鏡像對稱（x → -x），所以同一條路線對兩隊來說性質相同。

## 【Map Name】
貨櫃港口 PORT

## 【Theme】
貨櫃港口。北側是臨海碼頭與龍門吊，中間是貨櫃堆場，南側是兩棟倉庫夾出的走道與後巷。
地面是柏油加黃色標線，建築是藍灰色浪板倉庫，遠景是港邊吊臂與貨櫃。

## 【Combat Style】
Mixed：北長、中中、南短。

## 【Map Size】
Small～Medium（與其他地圖相同的 82 × 58 m 範圍）。

## 【Main Routes】
| 路線 | 位置 | 特性 | 掩體 |
|---|---|---|---|
| Route A 碼頭岸壁 | 北側 z -25～-18 | 長視線、掩體少，適合 DMR / 狙擊 / 步槍 | 繫船柱（低）、木箱（半）、龍門吊柱（全）、中央水泥擋（低） |
| Route B 中央貨櫃場 | 中間 z -10～10 | 主戰線，掩體最多，最容易正面交戰 | 單層貨櫃（全）、木箱（半）、中央雙層貨櫃 |
| Route C 倉庫走道 | 南側 z 14～21，兩棟倉庫之間 | 狹窄、有貨架隔出兩條窄道，適合 SMG / 霰彈 | 貨架（全）、木箱（半） |

## 【Flank Routes】
- **Flank A 港區服務道路**（z -15～-10）：從出生區北出口沿貨櫃列走，接到中央貨櫃場北側，可從側面打中央。沿途有堆高機、木箱、水泥擋。
- **Flank B 倉庫後巷**（z 25.4～29）：南倉庫後方的窄巷，繞到南側卸貨區，再從南邊進中央。

兩條側翼都通到中央區域的側面。出生區三面有牆，後方是地圖邊界，沒有路可以繞到出生點後方。

## 【Central Area】
中央貨櫃場：正中央是一組雙層貨櫃（5.4 m），擋住兩隊出生區之間所有直線視線；兩側各有單層貨櫃與木箱。
正南方是**中央高台**（1.35 m，兩側各一座樓梯）。
- 入口：西（中路）、東（中路）、北（服務道路與碼頭缺口）、南（卸貨區、倉庫走道出口）
- 撤退：雙層貨櫃南北兩條通道、北往服務道路、南往卸貨區

## 【Spawn】
- Team A：西端，x -41～-30；Team B：東端（鏡像）
- 每個出生區三個出口：正面（中路）、北角（碼頭與服務道路）、南角（倉庫走道與後巷）
- 出生區附近沒有高價值點；出生區內兩隊互看視線為 0（程式抽樣 1,350 條視線驗證）
- 重生保護 2 秒，重生時選離敵人最遠的位置

## 【Vertical Gameplay】
1. **卸貨平台**（兩隊各一座，1.8 m，西側三階樓梯）：站上去看得到碼頭與服務道路；平台東端有一道半身擋牆可以探頭。
2. **中央高台**（1.35 m，東西各一座樓梯）：看得到中央與卸貨區，但四周都能打到它。

反制：
- 對方有一座對稱的卸貨平台（另一個高點）
- 中央雙層貨櫃與倉庫擋住跨圖視線
- 服務道路可以繞到平台樓梯後方
- 平台上的人會被碼頭與服務道路兩邊夾擊

## 【Cover】
貨櫃（全掩體 2.7 m／5.4 m）、倉庫（全）、龍門吊柱（全）、貨架（全）、木箱（半 1.1 m）、水泥擋（低 1.2 m）、繫船柱（低 0.8 m）、堆高機（半 1.6 m）

## 【Weapon Recommendation】
- 長：LX-5、SV-2、DMR-6、MR-8 → 碼頭、卸貨平台
- 中：AR-7、Burst-4、K-8、R-5 → 中央貨櫃場、服務道路
- 近：MP-7、V-9、SM-12、霰彈槍、手槍、近戰 → 倉庫走道、後巷

## 【Map Risk】
- 碼頭是全圖最長的視線，狙擊槍在那裡會很強
- 卸貨平台可以壓制服務道路
- 中央高台可能被一方長時間佔住

## 【Counterplay】
- 碼頭：龍門吊柱與中央水泥擋可以逐段推進；也可以走服務道路從側面打碼頭上的狙擊手
- 卸貨平台：從服務道路繞到樓梯；用對方無法同時顧到的碼頭＋服務道路兩面夾擊
- 中央高台：從北、南、東、西四個方向都打得到；雙層貨櫃讓人可以貼近而不被看到

## 自我檢查
| 項目 | 結果 |
|---|---|
| 適合 5v5 | 是（10 AI 模擬 3 分鐘，雙方約 40 殺） |
| 3 條主要路線 | 是（碼頭／中央貨櫃場／倉庫走道） |
| 2 條繞後路線 | 是（服務道路／倉庫後巷） |
| 中央戰區 | 是，4 個入口、多條撤退路線 |
| 近／中／遠距離戰區 | 是 |
| 足夠掩體 | 是，全／半／低三種混合 |
| 高低差 | 是，3 座可上去的平台 |
| 高點可反制 | 是，每個高點至少兩種方法 |
| 出生區安全 | 是，兩隊出生區互看 0 條視線；中央高台看不到出生區 |
| 容易 Spawn Camp | 低：出生區有三個出口與重生保護 |
| 唯一最佳路線 | 否：AI 模擬中 6 條路線都會被使用 |
| 某武器過度強勢 | 狙擊在碼頭較強，但只佔一條路 |
| 長時間跑圖 | 否：出生 → 中央約 8 秒、→ 側翼約 8～10 秒 |
| 3 分鐘可玩 | 是 |
| 10 分鐘不重複 | 路線多，每次重生可以換路 |

> 跑圖時間比規格建議的 10～20 秒短，因為所有地圖共用同一個場地大小；這張地圖節奏會偏快。
