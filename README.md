# 火線交鋒 FIRELINE

在瀏覽器裡玩的 5v5 團隊死鬥第一人稱射擊遊戲。擊殺賺金幣，回重生基地買槍，死亡後重生再戰。

- **單機對戰（AI）**：你加上 4 名 AI 隊友，對抗 5 名 AI 敵人。不需要網路。
- **線上對戰**：建立房間、把 4 個字元的房間代碼傳給朋友，最多 10 人同房。房主可以用 AI 補位，命中、傷害、擊殺、金幣都由伺服器判定。

## 快速開始

需要 [Node.js](https://nodejs.org/) 18 以上版本。

```bash
npm install
npm start
```

打開 <http://localhost:3000>。

> 單機模式也要用 `npm start` 開啟。遊戲程式是 ES module，直接雙擊 `index.html`（`file://`）瀏覽器會擋下載入。

### 自己一個人測試線上模式

1. 開兩個瀏覽器分頁，都連到 <http://localhost:3000>
2. 分頁一：主畫面 →「線上對戰」→「建立房間」，記下房間代碼
3. 分頁二：「線上對戰」→ 輸入房間代碼 →「加入房間」
4. 回到分頁一（房主）選地圖、時間，按「開始對戰」
5. 兩個分頁都點一下畫面鎖定滑鼠，就能互相對戰

想要更熱鬧，房主可以在大廳按「空位補滿 AI」或每隊的「＋ AI」，並選 AI 難度（新手／標準／老手）。

### 跟同一個 Wi-Fi 的朋友玩

伺服器預設監聽所有網路介面。查出你電腦的區網 IP（Windows：`ipconfig`，macOS：`ipconfig getifaddr en0`），朋友用 `http://<你的 IP>:3000` 連進來即可。第一次可能要允許防火牆放行 Node.js。

### 只玩單機：GitHub Pages

單機模式不需要伺服器，可以直接放在 GitHub Pages：repo 的 Settings → Pages → Branch 選 `main`、資料夾 `/ (root)` → Save。
幾分鐘後網址是 `https://<帳號>.github.io/fireline/`。這個網址上「線上對戰」會停用，因為 GitHub Pages 不能跑遊戲伺服器。

### 換連接埠

```bash
PORT=8080 npm start          # macOS / Linux
$env:PORT=8080; npm start    # Windows PowerShell
```

## 操作

| 按鍵 | 功能 |
|---|---|
| W A S D | 移動 |
| 滑鼠 / 左鍵 / 右鍵 | 瞄準 / 射擊 / 開鏡（有瞄準鏡的槍） |
| R | 換彈 |
| H | 使用戰地醫療針（4 秒內恢復 35 HP，被擊中會中斷） |
| B | 在購買區開啟購買選單 |
| 1 / 2 / 3、Q、滾輪 | 主武器 / 手槍 / 近戰、切回上一把、輪流切換 |
| 右鍵（武士刀） | 衝刺拔刀斬，冷卻 5 秒 |
| 按住右鍵（戰斧） | 蓄力，放開重擊，最高 130 傷害 |
| Tab | 戰績 |
| M | 靜音 |
| Esc | 暫停 |

手機會自動切換成虛擬搖桿與按鈕，建議橫向持握。

## 專案結構

```
client/            瀏覽器端
  index.html       畫面結構
  style.css        介面樣式
  game.js          遊戲本體：3D 場景、移動、戰鬥、AI、介面、線上模式
  net.js           WebSocket 連線與伺服器時鐘同步
shared/            伺服器和瀏覽器共用
  game-data.js     武器數據、裝備、價格、4 張地圖配置
  sim.js           碰撞、尋路（A*）、射線判定、移動物理
  protocol.js      連線訊息格式與同步頻率
server/
  index.js         HTTP（提供遊戲檔案）+ WebSocket（/ws），同一個連接埠
  rooms.js         房間、大廳、隊伍、AI 補位設定、訊息轉發
  match.js         對戰權威模擬：AI、命中判定與延遲補償、傷害、經濟、重生
```

## 目前進度（v0.2）

**已完成**

- 單機模式完整保留：4 張地圖（可選「隨機」，每局開局才抽）、23 把武器（含小刀、武士刀、戰斧）、5 種裝備（含頭盔、戰地醫療針）與 6 種分槍種的擴充彈匣、商店價格依對戰時間調整、準心自訂
- 線上房間：建立 / 加入（房間代碼）、自動分隊、換隊、房主選地圖（含隨機，每局重抽）、時間與 AI 難度、房主離開時自動移交
- **AI 補位**：房主可幫每隊加減 AI，或一鍵補滿；有真人加入時 AI 自動讓位
- **伺服器判定戰鬥**：命中（含延遲補償，回推到你開槍當下看到的敵人位置）、爆頭、傷害、護甲、擊殺、連殺獎勵、金幣、購買、重生
- 移動驗證：伺服器限制最高移動速度，並阻擋穿牆
- **身分辨識**：隊友頭上一律顯示名字；敵人只有在準心對到且沒有牆擋時才顯示名字；AI 名字後面有 `[AI]`
- 擊殺訊息、比分、戰績（Tab）全員同步

**尚未完成**

- 客戶端預測與校正：目前你自己的移動是即時的，但伺服器判定被拒時不會把你拉回
- 對戰中不能中途加入；斷線後不能重新連回同一局
- 外觀自訂

## 連線協定

所有訊息都是 JSON，格式 `{ t: 類型, ...欄位 }`，完整說明寫在 [`shared/protocol.js`](shared/protocol.js)。
